Đang đọc

⭐ Giọng HoaiMy và NamMinh là giọng AI Neural của Microsoft — rất tự nhiên. Cần deploy Cloudflare Worker trước (xem hướng dẫn bên dưới).

1. Vào workers.cloudflare.com → Đăng ký miễn phí
2. Nhấn Create Worker → xóa code mẫu
3. Copy toàn bộ code trong file cloudflare-worker.js → paste vào
4. Nhấn Deploy → copy URL dạng https://tên.workers.dev
5. Dán URL đó vào ô Worker URL bên trên → xong! 🎉

Miễn phí 100,000 request/ngày — đủ dùng cả năm.
